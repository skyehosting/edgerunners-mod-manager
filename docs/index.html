Your all-in-one modding hub

Modding Cyberpunk usually means a browser, a downloader, a load-order tool, a log viewer and a lot of guessing. Here it is one app.

⇣

One click from Nexus

Browse and search Nexus inside the app. Pick the files, and the mods they need come along.

◧

A setup per playthrough

Profiles keep different mods and load orders apart. Switch from the sidebar in one click.

⚠

Know why it crashed

Every mod's log in one live timeline, kept per play and per profile, with crashes traced to a mod.

✦

A helper that reads logs

An optional AI explains errors in plain words and suggests fixes. It changes nothing without your OK.

Built to stay out of your way

  • Mods install to a staging folder and link into the game, so turning one off leaves no trace.
  • Conflicts show who wins each file, and you choose the winner.
  • Already use Vortex or Mod Organizer 2? Its mods and profiles carry over, without copying a byte.
  • Updates for your mods, and for the app itself, arrive on their own.
  • A short welcome walks you through setup the first time. Every step can be skipped.

Get it running in a minute

  1. Download it for your system, the latest release.
  2. Run it. Windows: the installer sets it up for your account, no admin needed (Windows may ask once before running a new app). Linux: make the AppImage runnable (chmod +x Edgerunners-Mod-Manager.AppImage, or tick "Allow executing" in its properties) and open it, or install the .deb on Debian, Ubuntu or Mint.
  3. Follow the welcome. It finds your game and connects your Nexus account with your personal API key.

Always the newest build. All releases

You'll need

Windows 10 or 11 with Cyberpunk 2077 (Steam, GOG or Epic), or Linux with the game on Steam (Proton). And a free Nexus Mods account: Premium makes downloads direct.

Updates

The app updates itself in the background and installs the new version when you restart it (Windows and the AppImage). The .deb does not: download the newest one to update.

Your keys stay yours

Your Nexus and AI keys are encrypted on your PC and never leave it except to talk to those services.

Open source, built in the open

All of the app's code is on GitHub. Every release is built from it by GitHub Actions on GitHub's own Windows machines: the tests run, the code and then the built app are scanned for keys, and only then is the installer published. The workflow file is in the repository, and each run's log shows every step.

  1. Install the tools: Git, Node.js 24 and 7-Zip (the app ships 7-Zip's own program, unchanged, to unpack mods).
  2. Get the code and its packages: 
    git clone https://github.com/skyehosting/edgerunners-mod-manager.git
cd edgerunners-mod-manager
npm ci
    To build one exact release, check out its tag before npm ci, e.g. git checkout v1.1.121 (the newest).
  3. Run the tests (optional): npm test
  4. Add 7-Zip to the build (PowerShell): 
    New-Item -ItemType Directory -Force build\7zip
$7z = "C:\Program Files\7-Zip"
Copy-Item "$7z\7z.exe","$7z\7z.dll","$7z\License.txt" build\7zip
  5. Build the installer: npm run dist. It lands in dist\ as Edgerunners-Mod-Manager-Setup-<version>.exe (GitHub's builds stamp the release number in first; a local build keeps the version in package.json).

Just want to run it?

After step 2, npm start opens the app straight from the code, with nothing installed.

What's inside

JavaScript on Electron, no closed parts. The installer is made by electron-builder; 7-Zip is the only program bundled with it, with its license.
